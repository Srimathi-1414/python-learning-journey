# Student Grade Calculator 🎓

A beginner-friendly Python mini project that collects student details and subject marks, calculates total and average marks, assigns grades, and determines PASS/FAIL status.

## Features
- Student name and roll number input
- Subject-wise marks collection
- Total and average calculation
- Automatic grade calculation
- PASS/FAIL checking
- Input validation

## Concepts Used
- Variables and data types
- Input and output
- Lists
- For and while loops
- Conditional statements
- Functions such as `sum()`, `len()` and `all()`
- Exception handling (`try` and `except`)

## Tools
- Python 3
- Google Colab
- GitHub
