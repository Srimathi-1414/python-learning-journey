# Student Performance Analysis

## Project Overview

This project focuses on analysing student academic performance using Python libraries such as Pandas, NumPy and Matplotlib.

## Objectives

- Create and explore a student performance dataset.
- Perform basic data cleaning.
- Calculate statistical summaries.
- Analyse department-wise student performance.
- Visualize student data using bar charts, line charts and pie charts.
- Draw meaningful conclusions from the analysis.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project File

`Student_Performance_Analysis.ipynb`

## Key Concepts Learned

- DataFrame creation and exploration
- Handling missing values and duplicates
- Statistical analysis
- Grouping and aggregation
- Data visualization

## Learning Outcome

Gained practical experience in data handling, data cleaning, statistical analysis and data visualization using Python libraries.
